# Aula de Predição

Repositório com materiais e códigos das aulas de Modelagem Preditiva e Machine Learning.

## Estrutura do Projeto

```
├── aulas/              # Apresentações e materiais de cada aula
├── dados/              # Datasets utilizados nas aulas
├── scripts/            # Scripts Python auxiliares
└── exercicios/         # Atividades e exercícios
```

## Conteúdo

### 📚 Aulas
- Modelagem Preditiva (apresentação)

### 📊 Dados
- **Dados de Treinamento.xlsx** - Dataset para prática de modelagem preditiva

### ✏️ Exercícios
- **Atividades - Modelagem Preditiva.docx** - Atividades práticas sobre modelagem preditiva

## Requisitos

- Python 3.8+
- Jupyter Notebook

### Instalação das Dependências

```bash
pip install -r requirements.txt
```

## Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/rodrigopimentel12/aula-predicao.git
cd aula-predicao
```

2. Instale as dependências:
```bash
pip install -r requirements.txt
```

3. Abra o Jupyter Notebook:
```bash
jupyter notebook
```
